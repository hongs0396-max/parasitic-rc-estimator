# Parasitic RC Estimator (기생 RC 추정기)

[English](README.md)

레이아웃 형상과 공정의 단위 파라미터로 회로 노드의 기생 커패시턴스·저항을 추정하고,
측정된 Pre/Post-layout 지연 증가분 중 그 기생 부하가 얼마나 설명하는지 확인하는
Python 도구입니다.

직접 설계한 스탠다드 셀 레이아웃(0.5 µm CMOS, Calibre PEX)에서 발견한 지연 이상치를
다시 검토하기 위해 만들었습니다.

## 배경

Calibre PEX 이후 NOR2의 하강 지연이 **44 ps에서 270 ps(+513%)**로 늘었습니다. 셀 6종
중 가장 큰 증가율이었습니다. 처음에는 출력–VSS 배선이 과다하게 그려진 것을 원인으로
추정했고, 이 도구는 그 추정을 수치로 검증하기 위해 만들었습니다.

## 방법

노드 하나에 대해 다음을 합산합니다.

- 드레인/소스 영역별 **접합 커패시턴스**: `면적 × C_area + 둘레 × C_fringe`
  (게이트와 맞닿은 변은 둘레에서 제외)
- 배선 구간별 **배선 커패시턴스**: `길이 × 폭 × C_area + 2 × 길이 × C_fringe`
- **배선 저항**: `길이 / 폭 × R_sheet`

그다음 합산값을, 측정된 지연 증가분을 설명하는 데 필요한 커패시턴스
`ΔC = I × Δt / ΔV`와 비교합니다. 구동 전류는 범위로 넣어 결과도 범위로 냅니다.

## 결과 (NOR2 vs. NAND2 출력 노드)

| | NOR2.Y | NAND2.Y |
|---|---|---|
| 접합 C / 배선 C | 3.8배 | 4.1배 |
| 배선 저항 | 약 4 Ω | 약 3 Ω |
| 하강 지연 증가 | +226 ps | +360 ps |
| 추정값이 설명하는 비율 (하강) | 필요 ΔC의 33~54% | 필요 ΔC의 34~58% |
| 추정값이 설명하는 비율 (상승) | 29~48% | 21~35% |

1. **NOR의 이상치는 주로 퍼센트 기준점 때문이었습니다.** 절대값으로는 NOR의 하강 지연
   증가가 NAND보다 작았고, +513%는 기준값 44 ps가 작아서 나온 수치였습니다. NOR의
   상승(+250 ps)과 하강(+226 ps)도 비슷하게 늘어, VSS 경로만의 문제가 아니라 출력
   노드에 부하가 추가된 것으로 보는 게 맞습니다.
2. **두 셀이 같은 패턴을 보였습니다.** 두 셀 모두 접합 C가 배선 C의 약 4배였고, 추정값이
   설명하는 비율도 비슷했습니다. 즉 NOR가 특이한 경우가 아닙니다. 회로도 넷리스트에는
   W/L/m만 있고 드레인/소스 면적이 없었기 때문에, 접합 커패시턴스는 추출 이후에 처음
   반영됐을 가능성이 높습니다.
3. **남은 한계.** 추정값은 지연 증가분의 1/3~1/2만 설명합니다. 직렬 스택의 내부 노드,
   입력 노드의 게이트 부하, 테스트벤치 영향은 모델에 없고, 구동 전류는 Idsat 기반의
   거친 범위이며, 형상은 레이아웃에서 직접 잰 근사값입니다(추출값 아님). 원인을 확정하려면 추출 넷리스트의
   노드별 C가 필요합니다.
4. **두 게이트만 다룬 이유.** 래치와 플립플롭은 여러 단으로 구성돼 clk-to-Q 지연이 여러
   내부 노드에 걸쳐 결정됩니다. 노드 하나만 보는 모델이 맞지 않고, 모든 내부 노드를
   손으로 측정하면 결론보다 측정 오차가 커집니다.

## 사용법

```bash
python rc_estimator.py --tech tech_template.csv --node nodes/nor_y.json nodes/nand_y.json
python test_rc_estimator.py
```

- `tech_template.csv`: 예시용 단위값입니다(실제 파운드리 PDK 값이 아님). 로컬에서 본인
  공정의 값으로 바꿔 사용하세요.
- `nodes/*.json`: 노드 형상(확산 영역, 배선)과 선택적인 지연 데이터입니다.

파운드리 공정 수치는 비공개 정보이므로 이 저장소에 포함하지 않았습니다.
